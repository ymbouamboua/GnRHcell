# Compare GnRHcell results across datasets

Combines dataset-level GnRHcell outputs to compare runtime, detected
GnRH cells, marker overlap, and optionally conserved marker programs.

## Usage

``` r
compare_gnrh_datasets(datasets, output_dir, run_programs = TRUE)
```

## Arguments

- datasets:

  A dataset configuration data frame containing at least `id` and
  `label`.

- output_dir:

  Character scalar giving the GnRHcell output directory.

- run_programs:

  Logical. Whether to compute conserved marker programs. Default is
  `TRUE`.

## Value

A named list containing:

- run_info_files:

  Run-information files included in the comparison.

- marker_files:

  Marker files included in the comparison.

- runtime_plot:

  Runtime comparison plot, if available.

- detected_plot:

  Detected GnRH cell comparison plot, if available.

- overlap:

  Marker overlap results, if at least two marker files are available.

- programs:

  Conserved marker program results, if requested and available.

## Details

The function expects outputs previously generated by
[`run_gnrh_collection()`](https://ymbouamboua.github.io/GnRHcell/reference/run_gnrh_collection.md)
or
[`run_gnrh_dataset()`](https://ymbouamboua.github.io/GnRHcell/reference/run_gnrh_dataset.md).

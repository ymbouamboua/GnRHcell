# Example GnRHcell Seurat object

A small example Seurat object for demonstrating GnRHcell functions.

## Usage

``` r
hpsc_gnrh
```

## Format

A Seurat object with 500 cells.

## Source

Derived from a small subset of a public scRNA-seq dataset.

## Examples

``` r
data(hpsc_gnrh)
hpsc_gnrh
#> An object of class Seurat 
#> 33538 features across 300 samples within 1 assay 
#> Active assay: RNA (33538 features, 2000 variable features)
#>  3 layers present: data, counts, scale.data
#>  3 dimensional reductions calculated: pca, harmony, umap
```

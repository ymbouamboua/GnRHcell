# Validate a GnRHcell multi-dataset collection

Performs cross-dataset validation of GnRH detection and developmental
staging results generated by
[`run_gnrh_collection`](https://ymbouamboua.github.io/GnRHcell/reference/run_gnrh_collection.md).

## Usage

``` r
validate_gnrh_collection(
  collection,
  output_dir = file.path(collection$output_dir, "validation"),
  positive_classes = c("direct", "supported"),
  validation_markers = NULL,
  assay = "RNA",
  layer = "data",
  write_output = TRUE,
  verbose = TRUE
)
```

## Arguments

- collection:

  An object of class `"gnrh_collection"` returned by
  [`run_gnrh_collection`](https://ymbouamboua.github.io/GnRHcell/reference/run_gnrh_collection.md).

- output_dir:

  Optional directory in which validation tables are written. Default is
  `file.path(collection$output_dir, "validation")`.

- positive_classes:

  Character vector defining positive GnRH detection classes. Default is
  `c("direct", "supported")`.

- validation_markers:

  Character vector of genes used for independent biological marker
  validation. If `NULL`, a predefined marker panel covering GnRH
  identity, migration, and neuroendocrine maturation is used.

- assay:

  Assay used for biological marker expression summaries. Default is
  `"RNA"`.

- layer:

  Expression layer used for biological marker expression summaries.
  Default is `"data"`.

- write_output:

  Logical. Whether validation tables should be written to disk. Default
  is `TRUE`.

- verbose:

  Logical. Whether to print progress messages. Default is `TRUE`.

## Value

An object of class `"gnrh_validation"` containing:

- `datasets`:

  Dataset metadata used for validation.

- `input_summary`:

  Number of cells and features per dataset.

- `detection`:

  GnRH detection summary.

- `dropout_candidates`:

  Summary of GNRH1-negative cells showing strong GnRH-like
  transcriptomic evidence. These cells are diagnostic candidates only
  and are not counted as GnRH-positive.

- `status_class`:

  Consistency between detection status and class.

- `scores`:

  Summary of GnRH evidence scores by detection class.

- `stages`:

  Developmental-stage distribution among GnRH-positive cells.

- `stage_class`:

  Developmental-stage distribution within each GnRH detection class.

- `stage_refinement`:

  Summary of raw-to-final stage refinement.

- `stage_reassignment`:

  Detailed raw-to-final stage transitions.

- `migration_core`:

  Migration-core evidence by raw stage.

- `migration_refinement`:

  Comparison of migration-core evidence between retained and reassigned
  migrating cells.

- `migration_refinement_summary`:

  Dataset-level summary of migration-stage refinement.

- `biological_markers`:

  Expression of selected biological validation markers by positive GnRH
  detection class.

- `output_dir`:

  Validation output directory, or `NULL`.

## Details

The function summarizes GnRH detection classes, consistency between
detection status and class, evidence scores, developmental stages, stage
refinement, migration-specific evidence, and selected biological marker
expression across datasets.

Processed Seurat objects must be present in the collection object.
Therefore,
[`run_gnrh_collection()`](https://ymbouamboua.github.io/GnRHcell/reference/run_gnrh_collection.md)
should normally be called with `clean_objects = FALSE` before running
this function.

## Examples

``` r
if (FALSE) { # \dontrun{
results <- run_gnrh_collection(
  datasets = datasets,
  output_dir = "gnrh_results",
  clean_objects = FALSE
)

validation <- validate_gnrh_collection(
  results
)

validation$detection
validation$stage_refinement
validation$migration_core
validation$migration_refinement
validation$migration_refinement_summary
} # }
```

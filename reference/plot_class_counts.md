# Plot GnRH classification counts

Plot GnRH classification counts

## Usage

``` r
plot_class_counts(object, txtsize = 9)
```

## Arguments

- object:

  A Seurat object processed by
  [`run_gnrh()`](https://ymbouamboua.github.io/GnRHcell/reference/run_gnrh.md).

- txtsize:

  Base text size.

## Value

A ggplot object.

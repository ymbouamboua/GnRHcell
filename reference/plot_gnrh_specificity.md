# Plot GnRH specificity landscape

Plot GnRH specificity landscape

## Usage

``` r
plot_gnrh_specificity(object, txtsize = 9)
```

## Arguments

- object:

  A Seurat object processed by
  [`run_gnrh()`](https://ymbouamboua.github.io/GnRHcell/reference/run_gnrh.md).

- txtsize:

  Base text size.

## Value

A ggplot object.

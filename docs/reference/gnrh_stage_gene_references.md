# GnRH developmental marker gene references

Returns a gene-level reference table for the curated developmental
programs used by
[`gnrh_stage_modules`](https://ymbouamboua.github.io/GnRHcell/reference/gnrh_stage_modules.md).

## Usage

``` r
gnrh_stage_gene_references()
```

## Value

A data frame with gene, program, evidence_class, and references.

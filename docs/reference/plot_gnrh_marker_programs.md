# Plot GnRH Marker Program Results

Visualize candidate GnRH marker programs generated by
[`gnrh_marker_programs`](https://ymbouamboua.github.io/GnRHcell/reference/gnrh_marker_programs.md).

## Usage

``` r
plot_gnrh_marker_programs(
  programs,
  table = c("summary", "high_confidence", "candidate_table"),
  type = c("bar", "dot", "tile"),
  min_genes = 1,
  style = "classic",
  mode = "light",
  txtsize = 12,
  x.ang = 45
)
```

## Arguments

- programs:

  Output list returned by
  [`gnrh_marker_programs`](https://ymbouamboua.github.io/GnRHcell/reference/gnrh_marker_programs.md).

- table:

  Character. Which result table to visualize. One of `"summary"`,
  `"high_confidence"`, or `"candidate_table"`. Default is `"summary"`.

- type:

  Character. Plot type to generate. One of `"bar"`, `"dot"`, or
  `"tile"`. For gene-level tables (`"high_confidence"` or
  `"candidate_table"`), this argument is ignored and a gene-level
  dotplot is returned.

- min_genes:

  Integer. Minimum number of genes required for a program/dataset
  combination to be displayed when `table = "summary"`. Default is `1`.

- style:

  Character. Theme style passed to
  [`plot_theme`](https://ymbouamboua.github.io/GnRHcell/reference/plot_theme.md).
  One of `"classic"`, `"minimal"`, `"bw"`, `"test"`, `"void"`,
  `"dirty"`, or `"gray"`. Default is `"classic"`.

- mode:

  Character. Theme mode passed to
  [`plot_theme`](https://ymbouamboua.github.io/GnRHcell/reference/plot_theme.md).
  One of `"light"` or `"dark"`. Default is `"light"`.

- txtsize:

  Numeric. Base text size passed to
  [`plot_theme`](https://ymbouamboua.github.io/GnRHcell/reference/plot_theme.md).
  Default is `12`.

- x.ang:

  Numeric. Rotation angle for x-axis labels. Default is `45`.

## Value

A `ggplot2` object.

## Details

This function generates publication-ready plots summarizing candidate
GnRH-associated marker genes, developmental programs, confidence levels,
and dataset-specific marker signatures.

When `table = "summary"`, three plot types are available:

- `type = "bar"`: barplot of candidate marker counts per developmental
  program, faceted by dataset.

- `type = "dot"`: dotplot showing developmental program enrichment
  across datasets.

- `type = "tile"`: heatmap-like tile plot showing the number of
  candidate genes per developmental program and dataset.

When `table = "high_confidence"` or `table = "candidate_table"`, the
function returns a gene-level dotplot with genes on the y-axis,
developmental programs on the x-axis, point color representing
confidence level, and point size representing specificity score.

The plotting theme is controlled by
[`plot_theme`](https://ymbouamboua.github.io/GnRHcell/reference/plot_theme.md),
the internal GnRHcell theme system.

## Examples

``` r
if (FALSE) { # \dontrun{
programs <- gnrh_marker_programs(
  files = files,
  results = overlap,
  outdir = outdir
)

# Summary barplot
p1 <- plot_gnrh_marker_programs(
  programs,
  table = "summary",
  type = "bar"
)

# Summary dotplot
p2 <- plot_gnrh_marker_programs(
  programs,
  table = "summary",
  type = "dot"
)

# Summary tile plot
p3 <- plot_gnrh_marker_programs(
  programs,
  table = "summary",
  type = "tile"
)

# High-confidence gene-level plot
p4 <- plot_gnrh_marker_programs(
  programs,
  table = "high_confidence"
)

# Dark mode
p5 <- plot_gnrh_marker_programs(
  programs,
  table = "summary",
  type = "dot",
  mode = "dark"
)
} # }
```

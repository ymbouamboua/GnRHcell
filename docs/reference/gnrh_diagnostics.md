# Run GnRH detection diagnostics

Generates diagnostic summaries for GnRH detection results, including
classification metadata, threshold performance curves, and summary
statistics.

## Usage

``` r
gnrh_diagnostics(object, verbose = TRUE)
```

## Arguments

- object:

  A Seurat object previously processed with
  [`detect_gnrh`](https://ymbouamboua.github.io/GnRHcell/reference/detect_gnrh.md).

- verbose:

  Logical; print progress messages. Default is `TRUE`.

## Value

A Seurat object with diagnostic results stored in `object@misc$gnrh`.

## Details

This function validates required detection outputs generated by
[`detect_gnrh`](https://ymbouamboua.github.io/GnRHcell/reference/detect_gnrh.md),
reconstructs a unified diagnostics table, computes total marker hits,
and evaluates classification performance across score thresholds using
sensitivity, specificity, precision, and F1 score.

Diagnostic outputs are stored in `object@misc$gnrh`.

Stored diagnostics include:

- `diagnostics`:

  Per-cell diagnostic table containing expression, scores, marker hits,
  and classification labels.

- `threshold_curve`:

  Threshold performance metrics across the composite score range.

- `best_threshold`:

  Threshold maximizing F1 score.

Required metadata columns:

- `gnrh_raw`

- `gnrh_expr`

- `gnrh_score`

- `gnrh_class`

- `gnrh_core_hits`

- `gnrh_mig_hits`

- `gnrh_neuro_hits`

- `gnrh_confident`

If fewer than two confident classes are present, threshold performance
metrics are skipped and a warning is issued.

Performance metrics are computed across evenly spaced thresholds:

- sensitivity

- specificity

- precision

- F1 score
